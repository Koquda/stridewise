Three separate sets. One fixed outcome.

Training fits a ridge linear regression. Calibration sets the absolute-residual interval width. The untouched test set measures error and empirical coverage. The mean baseline predicts the training-set mean for every test record.

Split conformal coverage is marginal under exchangeability. It does not guarantee coverage for an individual or a subgroup. Wider coverage settings produce wider intervals. All scores and bounds are clipped to the defined 0–100 outcome range.

Training ranges

Predictions outside these observed ranges are refused. Being inside each range does not prove a profile is well represented.

Important limits

No external validation, subgroup fairness assessment, temporal holdout, missing-data correction, or causal treatment estimates. Random splitting is a demonstration default. Retrospective deployment requires cohort-specific review and temporal or site validation.

Synthetic demo

Simulated outcomes. Explicit limitations.

The demonstration mobility index is an illustrative 0–100 scale. It is not a validated clinical instrument. The model predicts the score 12 weeks after the event using baseline age, mobility, pain, and time since event. A real dataset must define one consistent event, index, assessment protocol, and follow-up window.

Bring a retrospective cohort

Start the application with go run . -data /path/to/cohort.csv. Data stays on the server device. No upload service or external requests are used. Use pseudonymous IDs and access-controlled local files.

patient_id,age,baseline_mobility,baseline_pain,weeks_since_event,mobility_week12

At least 150 complete records are required, with one unique ID per person. The importer rejects invalid numbers, duplicate IDs, and values outside the accepted bounds. All predictors must be known at baseline. Outcome dates and measurement validity require independent source review.

How uncertainty is calculated

The model sorts absolute errors on the calibration set and uses the finite-sample corrected conformal quantile. The selected interval targets 80%, 90%, or 95% population coverage under exchangeable observations.
